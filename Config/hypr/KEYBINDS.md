# Keybinds - Hyprland

> Mod key: `SUPER` (Windows key)

## Core

| Keybind             | Action                   |
| ------------------- | ------------------------ |
| `SUPER + Return`    | Open terminal (kitty)    |
| `SUPER + SHIFT + Q` | Close window             |
| `SUPER + M`         | Shutdown / exit Hyprland |
| `SUPER + E`         | Open file manager (thunar) |
| `SUPER + F`         | Toggle floating window   |
| `SUPER + Space`     | Open menu (wofi)         |
| `SUPER + P`         | Pseudo tiling            |
| `SUPER + J`         | Toggle split layout      |

## Directional Focus

| Keybind     | Action      |
| ----------- | ----------- |
| `SUPER + ←` | Focus left  |
| `SUPER + →` | Focus right |
| `SUPER + ↑` | Focus up    |
| `SUPER + ↓` | Focus down  |

## Screenshots

| Keybind             | Action                |
| ------------------- | --------------------- |
| `SUPER + SHIFT + S` | Screenshot region     |
| `SUPER + SHIFT + W` | Screenshot window     |
| `SUPER + SHIFT + M` | Screenshot fullscreen |

## Misc

| Keybind             | Action                        |
| ------------------- | ----------------------------- |
| `SUPER + SHIFT + N` | Notification center           |
| `SUPER + SHIFT + B` | Toggle wallpaper              |
| `SUPER + V`         | Clipboard history             |
| `SUPER + SHIFT + T` | Open task manager (nvim)      |
| `SUPER + SHIFT + K` | Show keybinds (nvim)          |
| `SUPER + MOD5 + E`     | Open file manager (yazi)          |
| `SUPER + MOD5 + RETURN` | Open floating kitty              |

## Media Keys

| Key                     | Action                   |
| ----------------------- | ------------------------ |
| `XF86AudioRaiseVolume`  | Volume up (+5%)          |
| `XF86AudioLowerVolume`  | Volume down (-5%)        |
| `XF86AudioMute`         | Toggle mute              |
| `XF86AudioMicMute`      | Toggle mic mute          |
| `XF86MonBrightnessUp`   | Brightness up (+2%)      |
| `XF86MonBrightnessDown` | Brightness down (-2%)    |
| `XF86AudioNext`         | Next track               |
| `XF86AudioPause`        | Play / Pause             |
| `XF86AudioPlay`         | Play / Pause             |
| `XF86AudioPrev`         | Previous track           |

## Workspaces

| Keybind                 | Action                        |
| ----------------------- | ----------------------------- |
| `SUPER + [1-0]`         | Go to workspace 1-10          |
| `SUPER + SHIFT + [1-0]` | Move window to workspace 1-10 |
| `SUPER + Scroll Down`   | Next workspace                |
| `SUPER + Scroll Up`     | Previous workspace            |

## Mouse

| Keybind                | Action                      |
| ---------------------- | --------------------------- |
| `SUPER + Left Click`   | Drag window                 |
| `SUPER + Right Click`  | Resize window               |
| `3 fingers horizontal` | Switch workspace (touchpad) |
